# 📂 Project Data

This directory contains the dataset and analytical workbooks used for the **Smart Coffee Shop** project.

## ☕ 1. Raw Dataset: Coffee Shop Sample Data
The raw data files in this folder were sourced from Kaggle for educational purposes.

* **Primary Source:** [Kaggle - Coffee Shop Sample Data](https://www.kaggle.com/datasets/ylchang/coffee-shop-sample-data-1113)
* **Scope:** 9 CSV files covering transactions, pastry inventory, customer loyalty, and sales targets for April 2019.
* **Usage:** This data forms the basis for the relational database schema in the `SmartCoffeeShop` MySQL instance.

## 📈 2. Processed Analysis Workbook
* **File:** [Smart_Coffee_Shop_project.xlsx](./Smart_Coffee_Shop_project.xlsx)
* **Description:** The final validated workbook containing the cleaned transaction records and operational models.
* **Key Components:** * **ETL Logs:** Documentation of the data cleaning and transformation steps.
    * **Operational Models:** Pivot tables and statistical summaries for inventory waste and sales performance.
    * **Logic:** Includes the weighted average calculations and anomaly detection used in the final business report.
